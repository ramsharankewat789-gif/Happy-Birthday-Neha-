# 🎂 Happy Birthday Neha

A personalized, interactive birthday surprise web page built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## 🌐 Live Demo

👉 **[https://happy-birthday-neha-six.vercel.app/](https://happy-birthday-neha-six.vercel.app/)**

---

## ✨ Features

- **Password-protected entry** — Only the right person can open the gift
- **Animated gift box** — Click to unwrap a surprise reveal
- **Background music** — Plays automatically after unlocking
- **Birthday card** — A warm personal message with a beautiful script font
- **Animated film strips** — 12 personal photos scroll across the screen in cinematic film-reel style
- **Floating balloons & fireworks** — Colorful background animations to set the mood

---

## 🛠️ Built With

| Technology | Usage |
|---|---|
| HTML5 | Page structure |
| CSS3 | Animations, layout, film strip effects |
| Vanilla JavaScript | Password logic, gift interaction, dynamic background |
| Google Fonts | *Poppins* and *Great Vibes* typefaces |

---

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ramsharankewat789-gif/Happy-Birthday-Neha-.git
   ```
2. Open `index.html` in any modern browser.
3. Enter the password to unlock the experience.

> No build step or server required — it's a plain HTML file.

---

## 🔐 Password

The password is the birthday date in `DDMMYYYY` format.
